# MERN Stack Programs

A collection of MERN Stack and Node.js practice programs covering core JavaScript concepts, Node.js modules, Express routing, asynchronous programming, file system operations, streams, events, and MongoDB basics.

## 📌 Topics Covered

### JavaScript
- Callback Functions
- Callback Hell
- Promises
- Async / Await
- Asynchronous Programming

### Node.js Core Modules
- File System (fs)
- Path Module
- URL Module
- Event Emitter
- HTTP Module

### File Handling
- Read File
- Write File
- Append File
- Delete File

### Streams
- Read Stream
- Write Stream

### HTTP & Routing
- HTTP Server
- Handling Routes

### MongoDB
- Student Schema
- Basic CRUD Structure

### React
- React Application Setup

## 📥 Installation

Clone the repository

```bash
git clone https://github.com/your-username/MERN-STACK-Programs.git
```

Go to the project directory

```bash
cd MERN-STACK-Programs
```

Install dependencies

```bash
npm install
```

---

## ▶️ Run the Project

```bash
node server.js
```

or

```bash
node index.js
```

For React application

```bash
cd react-app-application
npm install
npm start
```

or (if using Vite)

```bash
npm run dev
```
